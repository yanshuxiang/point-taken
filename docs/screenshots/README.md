# README 截图清单

两份 README（`README.md`、`README.zh-CN.md`）引用这里的图片。文件名要和下表一致，放进来就能显示。

## 拍之前

- 桌面收拾干净：关掉聊天、邮件、账号名、通知；Dock 可以先隐藏（⌥⌘D）。
- 被标注的页面用一个中性网页（比如本项目的 GitHub 页面或一份公开文档），不要露出私人内容。
- 用 Retina 原尺寸截图，PNG。整屏的图用 16:10（例如 2880×1800）；窗口图用 ⌘⇧4 再按空格点窗口，自带阴影。
- 说话的内容用中文，和 README 里的示例一致，比如「这个按钮太小了，改大一点」。
