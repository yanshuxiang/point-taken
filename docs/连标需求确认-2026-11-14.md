## 后续实现：分页、检查、长图与历史

以下内容已接入源码；最终构建和安装验证见本节末尾。

- 屏幕采集排除连标自身窗口，每秒最多 5 帧；只在用户所在屏幕保留一个待处理帧，原始像素与可编辑笔迹分开保存。
- 分页通过前台应用/窗口/显示器变化，或输入之后的画面变化判断。滚动要求有实际像素变化；连续滚动等待停止和画面稳定后再接受下一次边界。它不是网页 DOM/URL 级识别，动态内容和快速切换仍需人工检查。
- 同一窗口继续滚动时保留后续不同画面，作为可选的长图输入。没有标记的画面默认待确认，不会自动作为图片发送。
- 点击缩略图、“回看”或转写文字打开检查界面；录音中不抢键盘焦点，文字持续刷新。结束后可修改交付稿，原始 `完整转写.txt` 保持不变。
- 检查界面支持自由画、矩形、圆圈、撤销、删页、排序、确认待选页。长图可纵向滚动查看和标注。删除图片不删除完整转写或音频。
- 每次选择接收应用，只自动粘贴、不自动发送。用户应预先在目标应用选好输入框；粘贴前验证目标应用确实已激活。没有辅助功能权限时仍提供文字复制和本地文件。
- “拼接下一页”使用 `screen-capture-macos` 的核心算法，未引入其 UI。对原图配准，以至少 0.97 的算法置信度和至少四分之一帧重叠作为保守接纳条件；该分数不是统计意义的成功概率。原始截图、原标注文件保留，重新映射可安全移动的笔迹。
- 当前长图只支持相邻同窗的向下滚动；反向滚动、不同窗口、不可靠配准、可能裁掉或错放标记的情况保留分图。暂不强行处理重叠区域内的第二页标记、固定侧栏和多个独立滚动区域，也不自动把所有页面合并。
- 每次会话写入 `页面.json`（原图、交付图、笔迹、包含状态、顺序、拼接源），并保留 `原始录音.wav`、`完整转写.txt`、`说明.md`；修改后的文字另存 `交付转写.txt`。
- 菜单栏与空闲灵动岛增加“独立听写”和“历史”。独立听写复用原本的本地模型/API 能力；进入连标时停止其键盘监听，结束后恢复。没有更换用户的模型或 API 设置。
- 历史没有自动过期；可以重新编辑、调用默认音频播放器播放原始录音、打开文件夹、手动移到废纸篓。
- 连标设置隐藏 OCR 页面及入口，快捷键页面仅保留连标开始键和独立听写键。手机遥控代码保留。
- 语音标点使用系统识别器的标点能力；尚未另接自动去口头词的整理模型，避免删除有意义的原话。

验证包含：音频样本逐点往返、完整转写边界、录音界面焦点/鼠标穿透、检查界面编辑与删页、合成页面的自动分页、长图逐像素顺序与标注坐标。真实麦克风长时间录音、跨应用实际粘贴与复杂网页滚动尚需实际使用验证。

## 转写遗漏修复（2026-11-14，真实录音回归）

真实会话暴露：系统本地实时识别在停顿后会返回新一句，且前一句的 `isFinal` 仍为 false；只有 `speechRecognitionMetadata` 表明这一句已稳定。旧累积器把后一句当成全段覆盖。用保存的原始录音逐块重放，修复前稳定丢失前句，修复后保留两句。

- 实时转写保留已稳定的句子，同时兼容连续累计结果；空的部分结果不再清除待定文字。
- 停止采音后，先收尾实时识别，再用本机已安装的系统模型读取整段原始 WAV。检查窗口等待这一过程结束，避免复制尚未完成的结果。不会为此上传录音或下载模型。
- `实时转写.txt` 保留实时结果，`完整转写.txt` 保存整段录音重转写结果；`转写状态.json` 区分 recording / finalizing / complete / incomplete。若模型不可用、失败或超过 60 秒，保留实时文字和原始录音并明确提示可能不完整。模型能返回结果并不代表识别准确率为 100%。
- 检查窗口仅在用户实际编辑文字后保存交付覆盖；`转写编辑.json` 明确记录用户编辑，包括有意清空。旧版空白的 `交付转写.txt` 会回退到原始转写。增加“恢复原始转写”。
- 页面摘录为空不能说明用户没有讲话，相关提示改为“此页没有单独的语音摘录，完整说明见上方转写”。
- 受影响会话的原始音频未修改；重新转写的文字已恢复，修复前文本及页面信息另存到该会话内的“修复前转写备份”。

验证包括真实录音逐块重放、已稳定句子后的识别重置、空部分结果、累计识别去重、停止后整段转写等待与保存、失败时保留原文、旧空白交付回退、明确编辑和恢复原始转写。
